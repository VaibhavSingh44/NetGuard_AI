<h1> Cyber_Guard_AI </h1>

<h3>Machine Learning-Based Network Intrusion Detection System</h3>

Developed a Scikit-learn classification pipeline using the UNSW-NB15 dataset to identify normal and malicious network traffic. 
<br>Implemented preprocessing, Logistic Regression and Random Forest models, and evaluated performance using precision, recall, F1-score, ROC-AUC, and confusion matrices.
